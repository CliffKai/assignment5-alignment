# Assignment 5: Alignment 学习笔记

## 目录结构

```
Notes/
├── README.md           # 本文件 - 总览和导航
├── plans/              # 计划与进度追踪
│   ├── roadmap.md      # 学习路线图
│   ├── progress.md     # 进度追踪
│   └── schedule.md     # 时间安排
├── learning/           # 学习笔记（概念理解）
│   ├── 01_basics.md
│   ├── 02_sft.md
│   ├── 03_policy_gradient.md
│   ├── 04_grpo.md
│   ├── 05_dpo.md
│   └── 06_evaluation.md
├── implementation/     # 实现笔记（代码相关）
│   ├── notes.md        # 实现过程中的发现
│   ├── bugs.md         # 遇到的 bug 和解决方案
│   └── optimizations.md# 优化技巧
├── questions/          # 问题记录
│   ├── unsolved.md     # 待解决的问题
│   └── solved.md       # 已解决的问题
└── references/         # 参考资料
    ├── papers.md       # 论文笔记
    └── resources.md    # 其他资源链接
```

## 快速导航

| 目录 | 用途 | 主要文件 |
|------|------|----------|
| `plans/` | 规划学习进度和时间安排 | `roadmap.md`, `progress.md` |
| `learning/` | 记录概念理解和知识点 | 按主题分的 md 文件 |
| `implementation/` | 记录实现细节和代码技巧 | `notes.md`, `bugs.md` |
| `questions/` | 记录遇到的问题 | `unsolved.md`, `solved.md` |
| `references/` | 收集参考资料 | `papers.md`, `resources.md` |

## 使用建议

1. **开始前**：先阅读 `plans/roadmap.md` 了解整体规划
2. **学习时**：在 `learning/` 对应文件中记录理解
3. **实现时**：在 `implementation/notes.md` 记录发现
4. **遇到问题**：先记录到 `questions/unsolved.md`
5. **解决后**：移动到 `questions/solved.md` 并记录解决方案
6. **定期更新** `plans/progress.md` 追踪进度
